# auxdisp-codex-quota — 更新日志

[English version](docs/en/CHANGELOG.md)

### 0.1.4

- 显示重置卡数量、每张卡的状态、到期时间与剩余时长；卡片独立分页，明确区分账户序号与卡片页码。
- 额度表新增重置倒计时；屏幕不再显示 CREDITS 占位信息。
- 正常停止及前台 Ctrl+C 时清屏并将亮度归零，重新启动恢复配置亮度；单独报告熄屏失败或未确认状态。
- CLI 改用明确子命令，无参数显示帮助；`status` 默认文字输出，结构化输出改用 `status --json`。
- 使用 `preview` 生成合成 PNG，默认保存到当前目录的 `auxdisp-codex-quota-preview.png`，支持 `--output`；移除公开 CLI 的测试参数，开发能力迁至源码脚本。

### 0.1.3

- 精简中英文用户文档，移除本地验收与迁移过程报告，保留使用指南和支持边界。
- 更新发布说明中的文档链接；应用运行行为不变。

### 0.1.2

- 修复用户级 pip 后台导入，加固任务生命周期、失败恢复与安全诊断。
- 完全移除运行时 PowerShell 后端，使用单一 Direct COM 后端。

### 0.1.1

- 修复 Windows Task Scheduler 用户名与 SID 表示差异导致的所有权误判；解析失败仍拒绝管理任务。
- 增加可诊断错误、身份解析回归测试及真实临时任务启停验收。完整变更见[中文记录](docs/zh/CHANGELOG.md)。

### 0.1.0

- 增加当前用户 Windows 后台计划任务、CLI 生命周期、单实例互斥锁与正常停止。
- 配置、轮转日志和匿名健康状态使用当前用户应用数据目录。
- 完整变更见[中文记录](docs/zh/CHANGELOG.md)。

- 从 PyPI 依赖已发布的 auxdisp-driver。
- 实现只读采集、窗口解析、历史快照与多账户轮播。
- 增加固定时钟、10 格额度条、离线预览与 USB 自动重连。
- 增加合成数据、异常恢复和安装验证测试。
