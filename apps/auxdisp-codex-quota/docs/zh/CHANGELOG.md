# auxdisp-codex-quota — 更新日志

[English version](../en/CHANGELOG.md)

### 0.1.4

- 显示重置卡数量、每张卡的状态、到期时间与剩余时长；卡片独立分页，明确区分账户序号与卡片页码。
- 额度表新增重置倒计时；屏幕不再显示 CREDITS 占位信息。
- 正常停止及前台 Ctrl+C 时清屏并将亮度归零，重新启动恢复配置亮度；单独报告熄屏失败或未确认状态。
- CLI 改用明确子命令，无参数显示帮助；`status` 默认文字输出，结构化输出改用 `status --json`。
- 使用 `preview` 生成合成 PNG，默认保存到当前目录的 `auxdisp-codex-quota-preview.png`，支持 `--output`；移除公开 CLI 的测试参数，开发能力迁至源码脚本。

### 0.1.3

- 精简用户文档，将本地验收与迁移过程报告移出正式文档和源码发行包。
- 同步整理中英文导航、支持边界及发布说明链接；应用运行行为不变。

### 0.1.2

- 运行时完全改用 Python Direct COM，移除 PowerShell Bridge 和编码命令，不提供自动回退；保留旧任务的身份与参数兼容。
- 后台使用 -E -P 支持标准 pip --user 安装，同时排除当前目录和 PYTHONPATH；Windows 依赖为 pywin32>=311。
- 加固禁用注册、验证后激活、失败快照恢复和明确残留/未知状态报告，并修复 Windows 省略默认 Enabled XML 节点的恢复问题。
- 增加安全错误分类、真实任务失败恢复验证，以及 wheel/venv、uv tool、标准用户级 pip 的真实 CLI 安装验证。

### 0.1.1

- 修复 Task Scheduler 将当前用户表示为用户名时误报所有权不匹配：先解析 SID，再校验身份；解析失败仍拒绝管理。
- 区分身份解析失败、身份不匹配、管理标记不匹配及动作不匹配错误，保留全部任务安全检查。
- 增加原生 Windows 身份解析回归测试，以及显式启用的真实临时任务生命周期测试。

### 0.1.0

- 增加当前用户 Windows 计划任务与 start/stop/status/restart/run/uninstall-service 命令。
- 增加命名互斥锁、正常停止信号、采集取消、有限崩溃重试和用户目录轮转日志。
- 配置默认切换为当前用户数据目录；开发目录配置需显式 `--config`。
- 按 TUI v3 调整为紧凑单行 Header、分列细进度条与固定 Footer。
- 账户名称与百分比使用 44px，其余文字统一为 24px；采用等宽字体和中文名称回退，长文本省略。
- Footer 保留轮播索引、READ ONLY、API 状态和 LAST OK，移除采集及轮播周期提示。
- 增加横排资源栏，未接入的数据明确显示 `N/A`；保留现有采集、轮播与 USB 行为。

- 从 PyPI 依赖已发布的 auxdisp-driver。
- 实现只读采集、窗口解析、历史快照与多账户轮播。
- 增加固定时钟、10 格额度条、离线预览与 USB 自动重连。
- 增加合成数据、异常恢复和安装验证测试。
